What is Natural Language Processing?

  • Interdisciplinary field between computer science and linguistics
  • Aims to quantitatively represent text so computers can “understand” it
  • Applications across sociology, political science, industry
  • Growing digital trace data → NLP is now transformative for daily life

Let’s talk a bit about Wikipedia

  • Free encyclopedia, volunteer-edited, hosted by Wikimedia since 2001
  • Reflects — and shapes — our contemporary knowledge production
  • What’s written on Wikipedia influences media, research, and real-life decisions
  • Editors skew male; political & interest groups actively edit pages

Web Scraping

Static vs. dynamic scraping

  • Static: scrape the rendered HTML of a page (e.g. rvest)
  • Dynamic: query an API directly (usually more efficient — no HTML parsing needed)

Text analysis workflow

The Document-Feature Matrix (DFM)

  • Rows = documents, columns = terms, cells = frequency
  • Bag-of-words assumptions: word order & grammar don’t matter, only presence/frequency
  • Gets sparse fast → trim rare/frequent terms

DFM example

tf-idf weighting

\[TF\text{-}IDF = TF \times \ln\!\left(\frac{N}{\text{docs containing } t}\right)\]

  • Raw counts assume every word is equally important — usually false
  • tf-idf up-weights words that are frequent in a document but rare across the corpus
  • dfm_trim() + dfm_tfidf() in quanteda
